# ASCEND — תבנית חנות בעמוד אחד

זו תבנית עיצוב בלבד: עמוד אחד, 10 כרטיסי מוצר, מקום לתמונות ומחירים.

## החלפת תמונות
ב-`index.html` ניתן להחליף את אזור `product-image` בתמונה אמיתית:
`<img src="images/product-01.jpg" alt="מוצר 01">`
צור תיקייה `images` והעלה אליה את התמונות.

## שינוי שמות ומחירים
המערך `products` נמצא בתוך `index.html`. אפשר לשנות שמות.
המחיר `₪00` נמצא בתוך תבנית הכרטיס.

## GitHub Pages
העלה `index.html`, `style.css` ו-`README.md` ל-repository.
Settings → Pages → Deploy from a branch → main → / (root) → Save.

הערה: תבנית זו אינה כוללת מנגנון להזמנת או מכירת חומרים רפואיים/מפוקחים.
